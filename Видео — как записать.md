# Видео геймплея — как записать (5 минут)

Записать видео сам я не могу: из Studio мне доступны только отдельные кадры, а программ для сборки видео на компьютере нет. Поэтому в игру добавлен **режим трейлера**: камера сама проходит по красивым планам, тебе остаётся только включить запись экрана.

## Готовый трейлер (~30 секунд)
1. Открой место в Studio и нажми **Play**.
2. Сделай окно Studio на весь экран, закрой лишние панели (Explorer, Output) — чем больше вид, тем лучше картинка.
3. Включи запись: **Win + Alt + R** (Xbox Game Bar, встроен в Windows). Видео сохранится в «Видео → Клипы».
4. Нажми **F8** в игре. Камера пройдёт пять планов:
   - хаб и облака сверху;
   - витрина редких деревьев крупно;
   - твой остров;
   - крутка с анимацией выпадения Phoenix Tree (интерфейс включён);
   - подъём над кольцом островов и титр **SPROUT RNG**.
5. Через ~32 секунды нажми **Win + Alt + R** снова, чтобы остановить запись.

Режим работает только в Studio: в опубликованной игре F8 ничего не делает.

## Живой геймплей (по желанию, 30–60 секунд)
Включи запись и сыграй сам: крутка → посадка → сбор урожая → открытие магазина → вход в подземелье и пара ударов. Лучше всего смотрится, если на острове уже растут редкие деревья.

## Куда загрузить
- **Страница игры Roblox**: Creator Hub → Places/Experience → **Thumbnails → Add Video** принимает ссылку на YouTube (нужен проверенный возраст аккаунта 13+).
- **TikTok / YouTube Shorts**: обрежь до 15–30 секунд, вертикально.
