# Иконки HUD — как добавить

Готовые картинки: папка `assets/icons` (11 PNG, 256×256, прозрачный фон).
Перерисовать: `python tools/make_icons.py`.

| Файл | Где в игре |
|---|---|
| island.png | кнопка ISLAND (слева) |
| odds.png | кнопка ODDS (слева) |
| dungeon.png | кнопка DUNGEON и кнопка атаки в подземелье |
| shop.png | кнопка SHOP (справа) |
| profile.png | кнопка PROFILE |
| menu.png | кнопка MENU |
| home.png | кнопка HOME |
| hub.png | кнопка HUB |
| coin.png | счётчик монет сверху |
| sprout.png | счётчик ростков и центр кнопки крутки |
| auto.png | кнопка авто-крутки |

Пока ID не вписаны, игра рисует иконки сама, так что ничего не сломается.

## Шаги в Roblox Studio

1. Открой место Garden RNG Dungeon.
2. Вкладка **Window** (или **View**) → **Asset Manager**.
3. В Asset Manager нажми кнопку **Bulk Import** (иконка со стрелкой вверх).
4. Выбери все 11 файлов из папки проекта `assets\icons` и нажми **Открыть**. Studio загрузит их в раздел **Images**.
5. Подожди пару минут: картинки проходят модерацию Roblox. Пока она идёт, иконка серая.
6. В Asset Manager → **Images** нажми правой кнопкой на картинку → **Copy ID to Clipboard**.
7. Открой файл `src/shared/Config/IconAssets.luau` и вставь ID в строку с тем же именем, например:
   ```lua
   island = "rbxassetid://1234567890",
   ```
8. Повтори для всех 11 картинок и сохрани файл. Rojo сам перенесёт изменения в Studio.

Проще: скопируй ID всех картинок и пришли мне списком «имя — ID», я впишу сам.

## Если что-то не так
- **Иконка не появилась.** Проверь, что ID начинается с `rbxassetid://` и картинка прошла модерацию.
- **Вместо картинки пустое место.** Скорее всего вставлен ID наклейки (Decal), а не картинки (Image). Бери ID из Asset Manager → Images, а не со страницы Decal на сайте.
- **Изменения не видны в Studio.** Перезапусти `rojo serve` в папке проекта и нажми **Connect** в плагине Rojo.
