# Сад RNG: Dungeon Survival (Roblox)

Roadmap: `Сад RNG Dungeon Survival (Roblox) — Roadmap.md` — источник истины по геймдизайну. Рекомендации по процессу: `Рекомендации — Claude + Roblox Studio.md`.

## Жёсткие правила
1. **Всё важное — на сервере**: броски крутилки, мутации, награды, покупки, начисление валюты. Клиент только показывает результат и шлёт запросы.
2. **Каждый RemoteEvent/Function валидируется на сервере** (тип, диапазон, владелец, частота запросов).
3. **Платного рандома нет.** Рандом только за монеты, заработанные игрой. Любая платная механика сначала проверяется по правилам платформы (платный случайный предмет, буст удачи тоже считается). Не использовать случайные награды в рекламе с вознаграждением.
4. **Шансы крутилки показываются числом по каждому исходу, сумма 100%.** Источник: `src/shared/Config/Rarities.luau`.
5. **Монетизация только предсказуемая**: геймпассы и товары разработчика (грядки, авто-сбор, питомец по выбору, косметика, множитель монет без влияния на шансы). Без таймеров-ловушек, «последнего шанса», давления на ребёнка. Цена всегда видна, ничего обязательного для прогресса.
6. **Смерть в подземелье**: теряется часть добычи, остальное в «сейфе», один бесплатный реквив за забег, без выкупа потерянного за Robux (пока не решено иначе — см. открытые вопросы в роадмапе).
7. **Mobile-first UI**: крупные кнопки, максимум 3 главных экрана (Сад, Крутилка, Подземелье), минимум текста, туториал до 2 минут.
8. Рост растений считается по серверному времени (`os.time()`), включая время без игрока.

## Код
- Luau, `--!strict` в каждом файле. Баланс и числа — только в `src/shared/Config/`.
- Скрипты правятся **только через файлы (Rojo)**, не в Studio. Через Studio MCP — только сцена (карта, модели, раскладка UI), плейтест и чтение Output.
- После правок: `stylua src` и `selene src`.
- Маленькие задачи, один коммит на задачу, сообщения коммитов по-русски или по-английски, но по сути.
- Не добавлять зависимости и новые механики вне роадмапа без согласования.

## Структура
- `src/shared` → ReplicatedStorage.Shared (Config, типы, утилиты)
- `src/server` → ServerScriptService.Server (сервисы)
- `src/client` → StarterPlayerScripts.Client (UI, анимации)

## Язык
Общение — по-русски. Интерфейс игры: английский основной, русский через Localization Table (уточнить).
